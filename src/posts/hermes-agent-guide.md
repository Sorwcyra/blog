最近发现，网上对 Hermes、OpenClaw 的讨论热情明显退减了——是大家已经偷偷用于自动化生产了，还是卸载到垃圾桶了？

我手上还有一台阿里云 2H2G 服务器空闲，小半年来一直把 Hermes Agent 部署在上面。我最大的感受是：**它真正被用起来，靠的不是多强的模型，而是你有没有把它当成一个全能的助手来使唤，让它真正成为你的工作伙伴。**

大多数人当时只是跟风安装，并没有找到真正适合自己的用法。它自己会记东西、能跑定时任务、能连外部服务，还能 SSH 回自己所在的机器改配置。把这些能力串起来，很多原本要自己起早贪黑盯着的活儿，现在可以全自动完成；电脑不在身边、没有开发环境时，你可以直接通过 QQ Bot 发送消息委派任务给它，让它帮你处理各种任务。

下面介绍我自己用 Hermes Agent 的一些落地用法。

## 1. RSS 推送

每天早上把 AI 相关新闻推送到你的聊天平台（QQ / 微信）。

**提示词模板**：

```
AI新闻推送：
每日检测 RSS: https://daily.juya.uk/rss.xml
从八点到十点，每十分钟检测一次，第一次推送后标记为已读状态不再推送，
推送的时候要确认好是否内容是当天日期的，不是则丢弃。
请把这个做成定时任务
```

这是 B 站 UP 主 [橘鸦 Juya](https://space.bilibili.com/285286947) 的 AI 新闻 RSS 源，内容质量不错，更新也很及时。你也可以换成其他 RSS 源，例如 L 站等等。

## 2. 服务器监控与 Docker 部署

让 Hermes 记住你的服务器信息，帮你监控状态、管理容器部署。

**提示词模板**：

```
我的服务器 [IP地址] 账号是 [账号]，SSH 端口是 [端口]，Docker 的路径是 [路径]，
请记住，当要你部署 Docker 的时候在 [路径] 部署。
```

几个落地建议：

- 让它把记录写成 memory，并补充你的操作习惯，比如 Docker 统一部署到哪个目录、偏好 `docker run` 还是 compose、喜欢本地映射还是持久卷；
- 部署新容器前先让它列一遍现有编排，避免端口冲突和重复镜像；
- 可以再加一条：**容器异常退出时主动通知你**，并附上最近若干行日志，省去自己登服务器排查的时间。

## 3. 修改自身配置

Hermes 自带的安全限制偶尔会挡住它自己改配置，比如 `hermes gateway restart` 这类操作它可能直接拒绝执行。

**提示词模板**：

```
你所在的机器的 IP 是 [IP]，账号是 [账号]，Root 的账号和密码是 [密码]，
你要修改配置的时候 SSH 自己所在的机器直接执行或修改配置。
```

## 4. 智能家居控制

米家的智能设备生态目前是最广的，小米官方的 API 也比较开放。我们可以通过将密码接入 Home Assistant，从而让 Hermes 控制家里的小米灯具、开关、插座、风扇等智能设备。

**前提条件**：

1. 部署 Home Assistant（可以让 Hermes 自行安装）；
2. 安装 HACS；
3. 安装 Xiaomi Home 集成。

**操作流程**：

1. 在 Home Assistant 中创建令牌（Token）；
2. 将令牌提供给 Hermes 进行配置。

只要设备能接进 Home Assistant，就能通过 Hermes 自然语言控制。比如直接说「把客厅灯调暗一点」「半小时后关掉风扇」，它都能帮你落到具体的服务调用上。

## 5. 跨会话记忆存储（Honcho）

Hermes 自带的记忆不够灵活，有长度限制，所以对话一多就容易忘事。用 [Honcho](https://github.com/plastic-labs/honcho) 作为跨会话记忆层，让它拥有长期记忆，不再每次对话都「失忆」。

**提示词模板**：

```
查看 Honcho: https://github.com/plastic-labs/honcho 这个项目，
尝试 SSH 到你所在的机器并部署，
使用 Honcho 作为跨会话记忆层接入 Hermes，启用后重启网关。
检查 built-in memory 里的凭据信息以及 system prompt 中的条目，
把全部凭证迁移过来，列举出其他记忆条目让我选择是否删除。
```

这一步记得换个智商高一点的模型来执行，Honcho 的部署和配置复杂一点，平常 Hermes 用 mimov2.5pro 或者 step3.7flash 就够了。

## 6. 邮箱验证码自动转发

让 Hermes 监控邮箱，自动提取验证码和认证链接转发给你，省得每次先开邮箱翻收件箱。

**第一步：注册腾讯的 Agent 邮箱（网易的 ClawEmail 也可）。** 在 [https://agent.qq.com](https://agent.qq.com) 注册一个 Agent 邮箱。

**第二步：安装 Agent Mail CLI。** 直接对它说：

```
请阅读 https://agent.qq.com/doc/cli-setup.md 文档，
按照步骤为我安装并配置 Agent Mail CLI。
```

**第三步：配置邮件转发。** 在其他邮箱（比如 Gmail、QQ 邮箱、Outlook 等）里设置把邮件转发到这个 Agent 邮箱。

**第四步：设置自动筛选。**

```
以后检查收到的邮件，如果是可用的验证码、Token 以及需要认证的链接，
请把邮件内容发送给我，其他内容忽略。
```

轮询频率建议别太快，每 2–3 分钟检查一次就够，避免触发 429。

## 结语

以上就是我用 Hermes Agent 的一些用法合集。核心思路其实只有一句话：**把它当成一个能记、能跑、能连、能改自己的全能助手，而不是一个只会聊天的模型。**

这些用法不需要多强的模型，也不需要多贵的服务器。真正拉开差距的，是你有没有把日常里那些重复的、琐碎的、需要定时盯着的活儿，一条条交出去。
