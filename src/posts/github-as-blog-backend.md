前阵子电脑触发 BitLocker，锁了一批本地数据。笔记、项目文件、一些只存在这台机器上的东西，就这么没了。

这件事之后我改了一个判断标准：**任何只在一份设备上的东西，我都当它是临时文件。** 博客笔记这种"我想长期保留、还想让别人看到"的内容，更不能只躺在硬盘里。

## 出问题的不是备份，是"唯一真源"

我的博客是 Astro 建的，笔记以前走的是这么一条链：

```
Obsidian（C:\Users\19112\Desktop\note）
   → sync-notes.mjs 转换
   → src/notes/*.md
   → GitHub Pages 发布
```

看起来没问题，但仔细想，`noteDir` 写死在本机路径上，整条链的**唯一真源**其实是那台电脑上的一个文件夹。电脑锁了，源就没了；仓库里只剩转换后的产物。

我真正需要的不是"定期复制一份到别处"，而是：源本身就应该在能异地访问的地方。

## 为什么选 GitHub 当后台

代码本来就 push 在 GitHub 上，Pages 也在那儿发布。再引入一个网盘或者数据库，只会多一个要维护的东西。

所以我把思路反过来：

> 不把 GitHub 当发布终端，把它当后台。

具体做法分三步：

1. **反推源文件。** 原来 Obsidian 里的 md 找不回来了，但线上已发布的 17 篇笔记都在 `src/notes/`。我从这些产物里把 frontmatter 剥掉，生成 `notes-src/<slug>.md`，作为新的唯一真源。
2. **改配置。** `notes.config.json` 的 `noteDir` 从本机绝对路径改成仓库内的 `notes-src`；每篇笔记加 `raw: true`，表示源文件已经是博客正文，不再做标题降级、双链替换那套转换。
3. **改同步脚本。** `scripts/sync-notes.mjs` 支持相对路径（相对仓库根目录解析），也支持 `raw` 模式。老转换逻辑保留着，但新笔记不再依赖本机目录。

提交、push、GitHub Actions 自动构建部署，网站照常更新。

## 代价我认了

这套改法不是没有成本：

- 仓库里同时有 `notes-src/` 和 `src/notes/`，内容重复了一份（一万多行文本）。但文本便宜，换来的是"仓库即后台"，值。
- 改笔记不能再像 Obsidian 那样随手改完就存，得走 git commit。这反而逼我每次改动都有记录，回头能查。
- 图片资源本来就在仓库的 `public/notes-assets/`，不受影响。

我还顺手把 Agent 接了进来：仓库 clone 到固定工作目录，`gh` CLI 登录，改完直接 commit + push；再挂一个每 15 分钟跑的监控，issue/PR/release 有动静就推到飞书。这样即使我不坐在电脑前，也能在手机上让 Agent 改博客。

有一度我图省事，写过一个走 GitHub REST API 的发布脚本——因为当时代理没开，git 连不上 `github.com:443`。后来代理开了，git 通道正常，那个脚本就删了。**能用标准工具就别自己造轮子**，这点在代理问题上体现得特别明显：不是工具坏了，是我没开代理。

## 顺带想清的另一件事：记忆放哪

同一段时间，我也在纠结 Hermes 的跨会话记忆 Honcho 要不要本地部署。

云端 Honcho 按量收费，本地部署能省下那笔写入费，听起来很香。但我想了两天，决定先不搬。

原因很直接：

- 云端那份记忆**不在这台电脑上**。我刚因为 BitLocker 丢过一次本地数据，现在把记忆搬回本机，等于把鸡蛋又放回同一个篮子。
- 本地方案不是免费，是把账单从 Honcho 换成我自己的 LLM token 费，外加 PostgreSQL、常驻进程、备份这些运维活。
- 真正烧钱的不是"存了多少字"，而是长对话触发的深度推理。把推理级别调低就够了，没必要为此换架构。

所以我的结论是：**云端买的是省心和异地留存，本地换的是控制权和一点费用，代价是你自己扛运维。** 对我这种刚被本地磁盘坑过的人，前者更合适。

## 给同样想改的人

如果你也在让 Agent 维护博客/笔记/知识库，我的建议就五条：

1. 找出你现在的"唯一真源"到底在哪。写死在本机路径上的，都算风险。
2. 把它迁到能从别的机器拿到的地方，Git 仓库是最省事的一种。
3. 源和生成物分开：源文件人手改，生成物脚本产出，别两头都改。
4. 自动化流程从仓库读，不要从 `C:\Users\...` 读。
5. CI/CD 负责发布，本地只负责改和提交。

我现在的工作流就很简单：在飞书里说一句"给博客加一篇笔记"，Agent 改 `notes-src/`，commit，push，Actions 上线。电脑锁不锁、Agent 在不在那台机器上跑，都不影响内容还在。

数据不在一台电脑里，我才睡得着。
